# Interface: BlendDeleteResult

Success payload of `blend delete`.

## Properties

### id

```ts
id: number;
```

Library id of the deleted blend.

***

### maximum

```ts
maximum: number;
```

The library's ceiling.

***

### name

```ts
name: string;
```

Display name it had when deleted.

***

### remaining

```ts
remaining: number;
```

How many blends the library still holds.
